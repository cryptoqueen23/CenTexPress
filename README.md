# CenTex Press

**Different voices. One community.**

CenTex Press is a digital-first Central Texas community newsroom.

## V1 goals

- WCAG 2.2 AA
- Fully responsive from 320px upward
- Light, dark, and system themes
- English / Español toggle
- Mobile burger navigation
- Fast, accessible article reading
- CenTex Flash summaries
- RSS-powered Live Wire
- Government Watch
- The Receipts source-document system
- Contributor profiles and editorial workflow
- Community submissions, tips, events, letters, and opinion
- Search, archives, SEO, social sharing, newsletter signup, and local advertising

## Planned stack

- Astro
- Cloudflare Pages / Workers
- Cloudflare D1 for workflow/account data
- Cloudflare R2 for documents and media

The newsroom should remain static-first, fast, and inexpensive to operate.
